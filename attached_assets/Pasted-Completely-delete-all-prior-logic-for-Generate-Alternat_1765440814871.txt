=========================================================
UNIFIED LOGIC FOR THIS FUNCTION
=========================================================

INPUT:
- BOX A = Theory T (one axiom-set)
- EXPLAIN toggle (ON or OFF)

GOAL:
Given theory T, produce **one or more alternative theories T′** such that:
1. T and T′ have the **same class of natural models** (i.e., they capture the same phenomenon).
2. T′ uses **different primitives**, or **recasts** the primitives into a different conceptual basis.
3. T′ is not a mere renaming; it must reorganize the conceptual structure in a formally meaningful way.

This function is NOT:
- a reduplication of the input
- a definitional equivalence test
- a rewriting function
- a model-theoretic transformation (unless needed to achieve conceptual shift)

It is strictly a **conceptual reframing** of the theory.

There are two output modes.

=========================================================
MODE 1 — EXPLAIN TOGGLE OFF (NON-EXPLAIN VERSION)
=========================================================

OUTPUT MUST HAVE:

1. ALTERNATIVE CONCEPTUALIZATION

**New Language:** { … }  
**New Axioms:**  
1. …  
2. …  

**Explicit Bridge Definitions (showing how to recover old primitives):**  
OldPredicate(x) ↔ <formula in the new language>

Rules:
- Output MUST be minimal and clean.
- New primitives MUST represent a genuinely different conceptual framing  
  (e.g., replace “R is a strict order” with “T is a reflexive-transitive closure”).
- Output two to four bridge definitions max.

NO prose explanation.  
NO analogies.  
NO commentary.

=========================================================
MODE 2 — EXPLAIN TOGGLE ON (EXPLAIN VERSION)
=========================================================

OUTPUT MUST HAVE:

1. ALTERNATIVE CONCEPTUALIZATION  
(same structure as above)

2. EXPLANATION  
(2–4 short paragraphs, formal tone)

EXPLANATION MUST:
- Describe why the new primitives constitute a *conceptual* reorganization.
- Explain how the new axioms capture the same natural models as the original.
- Clarify what structural or ontological viewpoint the new version emphasizes.

EXPLANATION MUST NOT:
- Introduce real-world metaphors, examples, or stories.
- Talk about models like numbers, graphs, networks, etc.
- Include philosophical digressions, metaphysics, or informal illustrations.

OUTPUT TEMPLATE (STRICT)
=========================================================

Example INPUT:
LANGUAGE: {R(x,y)}
AXIOMS:
1. ∀x ¬R(x,x)
2. ∀x∀y∀z ((R(x,y) ∧ R(y,z)) → R(x,z))

EXPLAIN = OFF

Example OUTPUT:

1. ALTERNATIVE CONCEPTUALIZATION

New Language: {T(x,y)}

New Axioms:
1. ∀x T(x,x)
2. ∀x∀y∀z ((T(x,y) ∧ T(y,z)) → T(x,z))

Bridge Definitions:
R(x,y) ↔ (T(x,y) ∧ x ≠ y)

-----------------------------

Example INPUT with EXPLAIN = ON:
(same theory)

Example OUTPUT:

1. ALTERNATIVE CONCEPTUALIZATION

New Language: {T(x,y)}

New Axioms:
1. ∀x T(x,x)
2. ∀x∀y∀z ((T(x,y) ∧ T(y,z)) → T(x,z))

Bridge Definitions:
R(x,y) ↔ (T(x,y) ∧ x ≠ y)

EXPLANATION:
The original theory uses an irreflexive relation R to characterize a transitive
ordering structure. The alternative formulation replaces R with a reflexive
relation T representing its closure under identity. This shifts the conceptual
basis: instead of starting from exclusion of self-relations, the new theory
treats reflexivity and transitivity as fundamental. Irreflexivity becomes a
derived feature of R through the bridge definition. The models of both theories
coincide, but the organizing principles differ, demonstrating an alternative
conceptualization of the same structure.
