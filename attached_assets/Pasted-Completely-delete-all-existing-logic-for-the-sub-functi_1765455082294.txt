=========================================================
NEW LOGIC FOR SUB-FUNCTION: SCHEMA EQUIVALENCE: DIRECT VOCABULARY MAPPING
=========================================================

TASK:
Given any theory T, build a NEW theory T* in a COMPLETELY DIFFERENT SIGNATURE
(same number of predicates, but ALL with HIGHER ARITY and DIFFERENT NAMES),
such that T and T* are definitionally equivalent.

You must also output an explicit TRANSLATION from T to T*.

=========================================================
CORE CONSTRUCTION
=========================================================

INPUT:
- LANGUAGE: any set of predicate symbols P1,...,Pk of various arities ≥ 1
- AXIOMS: any list of first-order sentences over that language
- EXPLAIN toggle (ON or OFF)

CONSTRUCTION:
1. Let the original predicates be:
      P1 of arity n1, ..., Pk of arity nk (each ni ≥ 1).

2. Introduce ONE NEW CONSTANT:
      c

3. For each Pi, introduce a NEW predicate symbol Hi with arity ni + 1.
   - Hi is a completely new name (not equal to any Pi).
   - Hi(x0, x1, ..., x_ni), where x0 will always be instantiated by c.

4. NEW LANGUAGE of T*:
   - All Hi of arity ni + 1, for i = 1,...,k
   - The constant symbol c
   - NO original Pi appear in the LANGUAGE of T*.

5. TRANSLATION (OLD → NEW), at the atomic level:
   - Replace every atom Pi(t1,...,t_ni) in every axiom with
         Hi(c, t1,...,t_ni).

6. The AXIOMS of T* are exactly the original axioms with all atoms
   rewritten using step 5.

7. Do NOT add any extra axioms beyond these rewritten ones.
   Do NOT keep Pi in the LANGUAGE of T*.
   Do NOT reject any input.

=========================================================
OUTPUT FORMAT (EXPLAIN = OFF)
=========================================================

When EXPLAIN = OFF, output ONLY the new theory and the translation.

FORMAT:

1. THE RESULT

LANGUAGE: { H1(c,x1,...,x_n1), H2(c,x1,...,x_n2), ..., c }

TRANSLATION (OLD → NEW):
P1(x1,...,x_n1) ↔ H1(c,x1,...,x_n1)
P2(x1,...,x_n2) ↔ H2(c,x1,...,x_n2)
...

AXIOMS:
1. <original axiom 1 rewritten>
2. <original axiom 2 rewritten>
3. ...

Rules:
- Every occurrence of Pi(...) MUST be replaced by Hi(c,...).
- Quantifiers and logical connectives are left unchanged.
- Only Pi-atoms change; all else stays exactly as in the original.

=========================================================
OUTPUT FORMAT (EXPLAIN = ON)
=========================================================

When EXPLAIN = ON, output the same RESULT block as above PLUS an
EXPLANATION block.

FORMAT:

1. THE RESULT
<same as EXPLAIN = OFF>

EXPLANATION:
- Each original predicate Pi has been replaced by a higher-arity
  predicate Hi with an extra c-argument.
- The translation Pi(x1,...,x_n) ↔ Hi(c,x1,...,x_n)
  gives a definitional equivalence between T and T*.
- T* is structurally different (different symbol names, higher arities),
  but has exactly the same theorems up to this translation.
- Keep the explanation short and formal.
