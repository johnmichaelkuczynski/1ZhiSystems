EXAMPLE 1 (SIMPLE) 

INPUT: 

1. IF X < Y, THEN NOT (Y < X)
2. IF X < Y AND Y < Z, THEN X < Z
3. IF, FOR ANY Z, (X<Z IFF Y<Z), THEN X=Y 

OUTPUT: 

Domain: the integers
Interpretation of <: the usual less-than on integers
Interpretation of =: ordinary numerical equality

1. If x < y, then not (y < x).

2. If x < y and y < z, then x < z.

3. If for every z, (x < z iff y < z), then x = y.

This is true because no two different integers have exactly the same set of integers greater than them.

EXAMPLE 2 (SIMPLE) 


INPUT (Axiom Set)

∀x∀y ( x < y → ¬(y < x) )

∀x∀y∀z ( (x < y ∧ y < z) → x < z )

∀x∀y ( (∀z (x < z ↔ y < z)) → x = y )

OUTPUT (Interpretation)

Domain: people in a line
Relation <: “is standing in front of”

Explanation:

Axiom 1 says: if Person A is in front of Person B, then B is not in front of A.
This matches any normal line: you can’t both be in front of each other.

Axiom 2 says: if A is in front of B, and B is in front of C, then A is in front of C.
True of any single-file line.

Axiom 3 says: if two people have exactly the same set of people behind them, then they are actually the same person.
In a real line, only one unique person can occupy a given position; no two positions have the same “people behind me” set.

Therefore this interpretation is true, fully intuitive, and mirrors exactly what the axioms describe:
a simple single-file line with the “in front of” relation.

EXAMPLE 3 (SIMPLE) 


INPUT (Axiom Set)

∀x ¬R(x,x)

∀x∀y ( R(x,y) → R(y,x) )

∀x∀y∀z ( (R(x,y) ∧ R(y,z)) → R(x,z) )

OUTPUT (Interpretation)

Domain: people
Relation R(x,y): “x is a sibling of y”

Explanation:

Axiom 1: ¬R(x,x)
No one is a sibling of themselves. True and intuitive.

Axiom 2: R(x,y) → R(y,x)
If A is B’s sibling, then B is A’s sibling. Siblinghood is symmetric.

Axiom 3: (R(x,y) ∧ R(y,z)) → R(x,z)
If A is a sibling of B, and B is a sibling of C, then A is a sibling of C.
This matches the ordinary idea of siblings: they all share the same parents, so siblinghood is “all-the-way across.”

EXAMPLE 4 (MEDIUM) 

INPUT (Axiom Set)

∀x ∃y R(x,y)

∀x∀y∀z ( R(x,y) ∧ R(x,z) → y = z )

∀x∀y∀z ( R(x,y) ∧ R(y,z) → R(x,z) )

∀x ¬R(x,x)

OUTPUT (Interpretation)

Domain: all natural numbers (0,1,2,3,…)
Relation R(x,y): “y is the unique child of x”

Explanation:

Axiom 1: ∀x ∃y R(x,y)
Every person has exactly one child.
(Not true in real life, but perfectly fine as a mathematical structure.)

Axiom 2: If x has R-relation to both y and z, then y = z.
Each person has exactly one child.

Axiom 3: If y is the child of x, and z is the child of y, then z is the grandchild of x.
This makes R a kind of “ancestry step” we can iterate.

Axiom 4: ∀x ¬R(x,x)
No one is their own child.
(Rules out loops.)

Interpretation that satisfies all axioms:
Let each natural number’s “child” be its successor.

Child(0) = 1

Child(1) = 2

Child(2) = 3

…

So we define:

R(x,y) ⇔ y = x+1

This fits the axioms perfectly:

Every number has exactly one successor.

Successor is unique.

Successors chain transitively (x+1)+1 = x+2.

No number is its own successor.


EXAMPLE 5

INPUT (Axiom Set)

∀x ∀y ∀z ( R(x,y) ∧ R(y,z) → R(x,z) )

∀x ∀y ( R(x,y) ∧ R(y,x) → x = y )

∀x ∃y R(x,y)

∀y ∃x R(x,y)

∀x ∀y ( R(x,y) ∨ R(y,x) )

∀x ∀y ∀z ( (R(x,y) ∧ R(x,z)) → (R(y,z) ∨ R(z,y)) )

OUTPUT (Interpretation)

Domain: the set of all integers
Relation R(x,y): “x ≤ y” (the usual less-than-or-equal ordering)

Explanation of why this is difficult:

Axioms 1 and 2 say R is a strict order without cycles.

Axiom 3 says every element has something above it.

Axiom 4 says every element has something below it.

Axiom 5 says every pair is comparable (totality).

Axiom 6 forces a deep structural property:
If one element is below two others, the two others must be comparable.
This is a way of encoding that R comes from a linear order, not just any partial order.

Why the interpretation works:

On the integers, ≤ is transitive (A1).

If x ≤ y and y ≤ x, then x = y (A2).

Every integer has a greater integer (A3).

Every integer has a lesser integer (A4).

Any two integers are comparable (A5).

If x ≤ y and x ≤ z, then y and z are comparable in the usual integer ordering (A6).

This is a nontrivial axiom set because:
• you cannot model it with naturals (fails 4),
• you cannot model it with reals (fails 3 and 4),
• you cannot model it with cycles (fails 1–2),
• you cannot model it with branching orders (fails 6).

The integers with ≤ is the smallest intuitive structure that satisfies all six axioms.

EXAMPLE 6  (VERY DIFFICULT) 

INPUT (Axiom Set)

∀x ¬R(x,x)

∀x∀y ( R(x,y) → ¬R(y,x) )

∀x∀y∀z ( R(x,y) ∧ R(y,z) → R(x,z) )

∀x ∀y ∀z ( R(x,y) → (R(x,z) ∨ R(z,y)) )

∀x ∀y ( ∃z (R(x,z) ∧ R(y,z)) → (R(x,y) ∨ R(y,x)) )

∀x ∃y ( R(x,y) ∧ ∀z ¬R(y,z) )

∀x ∃y ( R(y,x) ∧ ∀z ¬R(z,y) )

OUTPUT (Interpretation)

Domain: all integers
Relation R(x,y): “x < y and y = x + 1”, i.e. y is the immediate successor of x

This means R(x,y) is true only when y is exactly one step above x.

Explanation of why this interpretation works:

Axioms 1–3 say R is a strict, acyclic, transitive relation of “stepping upward.”

Axiom 4 says: if x steps to y, then for any z, either x steps (or eventually reaches) z, or z steps (or eventually reaches) y.
This forces the structure to be linear, no branching.

Axiom 5 says: if two elements share a common point above them, they must be comparable.
This eliminates trees, partial orders, and any branching order types.

Axioms 6 and 7 say:
• every element has a highest reachable successor (its immediate next step),
• every element has a lowest reachable predecessor (its immediate previous step).
This forces the structure to be a bilateral infinite chain with each point having a unique next and previous point.

The only natural intuitive structure that satisfies all seven axioms is:

The integers with the “immediate successor” relation.

Each integer n has a unique successor n+1.

Each integer n has a unique predecessor n−1.

All integers lie on a single infinite chain with no branching.

There are no endpoints in either direction.

EXAMPLE 7 (MATHEMATICAL)

INPUT (Axiom Set)

∀x∀y ( R(x,y) → R(y,x) )

∀x∀y∀z ( R(x,y) ∧ R(y,z) → R(x,z) )

∀x ∃y ( R(x,y) ∧ x ≠ y )

∀x∀y ( R(x,y) → S(x) = S(y) )

∀x∀y ( S(x) = S(y) → R(x,y) )

Where R is a binary relation and S is a unary function symbol.

OUTPUT (Interpretation)

Domain: all points on the Euclidean circle of radius 1 (the unit circle in the plane)

Interpretations:
• S(x) = the angle (in radians) of point x, i.e., its polar coordinate θ
• R(x,y) = “x and y lie at the same angle,” i.e., they are the same geometric ray from the origin

Explanation:

Axiom 1: R is symmetric.
If two points lie on the same angle, reversing the order doesn’t matter.

Axiom 2: R is transitive.
If x and y share an angle, and y and z share an angle, then x and z share an angle.

This says R is an equivalence relation representing “same direction from the origin.”

Axiom 3: Every point has some other distinct point at the same angle.
True on the circle: for any point, you can move outward or inward along the same ray and still land on the unit circle (you can even reflect across the center, if we interpret “same angle up to π”).
Or if you prefer the pure unit circle: two distinct points can share the same angle if you allow angle identification modulo 2π (explained below).

Axiom 4: If two points are angle-related, they have the same angle measurement.
True: “same ray” means same θ.

Axiom 5: If two points have equal angle, then R(x,y).
Again true by definition.

EXAMPLE 9 (PHYSICS) 

Domain: physical events in spacetime.

T(x): the coordinate time at which event x occurs.

R(x,y): “event x occurs strictly before event y in Newtonian time.”

Explanation in physical terms:

Axiom 1: R(x,y) → T(x) < T(y)
If x happens before y, its physical clock‐time is smaller.
This is literally how temporal ordering works in classical physics.

Axiom 2: (R(x,y) ∧ R(y,z)) → R(x,z)
If x happens before y, and y before z, then x happens before z.
Time order is transitive.

Axiom 3: If two events have the same numerical time, neither is before the other.
In Newtonian physics, simultaneity is absolute: equal time → no before/after relation.

Axiom 4: ∀x ∀t (T(x) < t → ∃y… )
For any event x and any later time t, there exists an event y that:
• happens after x
• happens exactly at time t
This describes continuous time: for any later moment, you can specify a physical event happening then.

Axiom 5: ∀x ∃y R(y,x)
Every event has some earlier event.
This reflects an infinitely extendable past, like Newtonian time stretching arbitrarily backward.

✅ EXAMPLE 31 — CASE (D): WOULD HAVE A MODEL IF SLIGHTLY MODIFIED

INPUT

∀x∀y (R(x,y) → ¬R(y,x))

∀x∀y∀z (R(x,y) ∧ R(y,z) → R(x,z))

∀x ∃y R(x,y)

Explanation:
This axiom-set is inconsistent.
Axiom 3 says: no element has a predecessor.
Axiom 4 says: every element has a successor.
Together these imply the structure is an infinite chain with a first element.
But Axiom 3 forbids the existence of a first element (because the first element would have no predecessor, which is allowed—but Axiom 3 incorrectly forbids all elements from having predecessors).

The issue:
Axiom 3 is too strong. It should say:

Modified Axiom 3 (adjacent interpretable version):
∃x ¬(∃y R(y,x))

i.e., at least one element has no predecessor.

With this repair, the structure becomes:

OUTPUT MODEL (for the adjacent corrected axiom-set)
Domain: natural numbers
R(x,y): “x is the immediate predecessor of y”

Now:

0 has no predecessor

every number has a successor

the order is strict and transitive

Thus while the original input is inconsistent, a one-symbol repair gives a perfect model.
